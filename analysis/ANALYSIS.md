# @claudeai 视频批量分析报告

77 个视频，时间跨度 2025-10-01 至 2026-05-11。
按 4 个时间段分别分析视觉风格演变。

---

# Batch 1: Oct–Dec 2025（21 个视频）

## 1. 视频类型分类

**主力类型：动画 UI 模拟（约 14/21）**
浮动应用窗口在品牌背景上，带模拟光标交互。不是原始录屏。代表：Desktop GA、Chrome、Skills、Code on Web。

**短社交卡片（约 5/21）**
8-13 秒，单场景文字 + 背景。代表：Azure 合作、meetup、guest passes、plugins marketplace。

**唯一真人出镜（1/21）**
Video 10（Opus 4.5 工程师讲述）是唯一带真人面孔的。

## 2. 视觉风格

**色彩体系：**
- 主背景：赤陶/烧橙色（~60% 视频），奶油/暖米色（~35%）
- UI 表面：深色模式（深炭灰）
- 这是有意的差异化策略——远离竞品的蓝/白冷色调

**品牌一致性：**
Claude 星号 logo（珊瑚/赤陶色）在所有官方视频中一致出现。

## 3. 字体

- 主标题：高对比度衬线字体（Editorial New 风格）
- 副标题/正文：干净的无衬线体（Inter/Helvetica 风格）
- 代码：等宽字体（JetBrains Mono / Fira Code）
- 句子式标题带句号——对话感和自信感

## 4. 转场

- **淡入黑色**（~40%）：最常见
- **滑入**（~15%）
- 所有转场都在 2 秒内
- 没有复杂的 morph 或 3D 转场

## 5. 节奏

- 30-95 秒的主力视频：多场景，每场景 5-12 秒
- 8-13 秒短卡：单场景或 2-3 个节拍
- 节奏紧凑，符合短视频社交惯例

## 6. 画幅比例与渠道

- **16:9 横屏**：YouTube / X 主力
- **4:5 竖屏 / 1:1 方形**：Instagram / X 社交
- 分辨率与产品类型相关：桌面/Web 产品用 4K，开发者工具用较低分辨率

## 7. 开场钩子（前 3 秒）

- ~50%：品牌背景 + 文字淡入
- ~30%：UI 窗口具现化
- 最吸引人的是异类：像素艺术（Video 7）、变形插画（Video 2）
- **没有 logo intro**——产品直接在前 2 秒展示

## 8. 结尾模式

- **Hold / 淡出 / 低调 logo 卡**
- 没有硬切到黑屏
- 不使用传统 CTA 结尾卡
- 强化"高级、自信"的品牌定位

## 9. 关键发现

1. 两大制作层级：主力发布用 30-95 秒 4K 多场景视频；小公告用 8-13 秒单场景社交卡
2. 赤陶色 + 深色模式 = Claude 视频即时辨识度
3. 真人出镜极少——品牌声音由文字、UI、动效承载
4. 分辨率与产品类别挂钩

# Batch 2: Jan–Feb 2026（15 个视频）

## 1. 视频类型分类

**动效图形 / 高保真 UI 模拟（11/15）**——主力类型：
- V01 Cowork 发布（68.6s，49.7M views）——最复杂的制作
- V04 Excel 集成（43.8s，23.4M views）——像素级 Excel UI 重建
- V05/V06 Cowork 多步骤演示——分屏：深色 UI 左 + 赤陶桌面右

**纪录片/艺术片（1/15）**：
- V10 Murakami 装置艺术（182s）——电影级运镜，完全不同风格

**概念测试（3/15）**：
- V12 达尔文肖像、V13 威尔士风景、V14 B&W 文字——可能是广告概念测试

## 2. 视觉风格

**核心组合：赤陶色 + 深色模式**
- 背景：暖中性色——米色/赤陶色
- UI 表面：深色模式深炭灰（#1A1A1A）
- 这个组合出现在 11 个产品视频中的 8 个

**例外：**
- V07 Clay：桃粉到黄橙渐变（Clay 品牌覆盖）
- V10：丰富的去饱和土色调
- V12：深褐色/琥珀色调

## 3. 字体

- 主标题：优雅衬线字体（编辑/高级感）
- UI 标签：无衬线体，常规和中等粗细
- 文件路径/技术元素：等宽字体
- 节标题：偶尔全大写（PROGRESS, WORKING FOLDER, CONTEXT）

## 4. 转场

- **硬切**为主要转场类型
- 面板滑动推开（Cowork 侧边栏）
- 从纯色淡入
- 缩放/放大到 UI 元素
- 快速横移（whip-pan）在 V01 中

## 5. 节奏

| 视频 | 时长 | 切割率 | 特点 |
|------|------|--------|------|
| V01 Cowork 发布 | 68.6s | 1-2s/切 | 非常快，节奏感强，节拍同步 |
| V04 Excel | 43.8s | 3-4s/切 | 中速逐步演示 |
| V05 Cowork 供应商 | 93.3s | 4-6s/切 | 详细多步骤 |
| V10 Murakami | 182s | 5-15s/切 | 电影纪录片 |
| V12-V14 | 60.1s | 无切割 | 单一连续镜头 |

## 6. 开场钩子

| 类型 | 视频数 | 代表 |
|------|--------|------|
| 痛点问题 | 3 | "Tired of tedious, non-technical work?" |
| 行动承诺 | 2 | "Let's knock something off your list" |
| 慢揭示 | 3 | 纯色背景 → UI 淡入 |
| 大胆声明 | 3 | "KEEP THINKING." |
| 好奇心 | 2 | 达尔文肖像 / 风景 |

## 7. 结尾模式

三种：
1. **"Start today" CTA + Claude logo**（V01, V06）
2. **最终功能状态 + 品牌**（多数产品视频）
3. **品牌宣言**（V10, V14, V15）："Keep Thinking"

## 8. 叙事弧线

**产品演示（标准 3 幕）：**
1. Setup（0-15%）：宣布能力或痛点
2. Demo（15-85%）：逐步 UI 演示
3. Resolution（85-100%）：完成结果 + logo

**Cowork 系列（4 拍）：**
1. "Let's knock something off your list"（承诺）
2. Claude 处理文件，显示思考/进度侧边栏
3. 有形输出（整理文件、供应商表格、市场分析）
4. "Start today" / Claude logo

## 9. 互动数据发现

| 视频 | 浏览量 | 类型 | 关键因素 |
|------|--------|------|----------|
| V01 Cowork | **49.7M** | 完整产品介绍 | 叙事驱动 + 音乐节拍 |
| V04 Excel | **23.4M** | 办公集成 | 熟悉工具 = 大覆盖面 |
| V15 Keep Thinking | **5.2M** | 品牌宣言 | 强烈观点 > 制作复杂度 |

## 10. 关键发现

1. **赤陶标准**：暖赤陶背景 + 深色模式 UI 浮于其上 = 最标志性视觉元素
2. **深色模式 = 高端**：所有产品视频都展示深色 Claude 界面
3. **Cowork 是核心**：4/15 视频专门讲 Cowork
4. **"Keep Thinking" 品牌进化**：从产品营销转向哲学品牌定位
5. **两大制作层级**：Tier 1（4K 高制作）vs Tier 2（720p-1080p 标准）
6. **模拟 UI 技术**：用动效软件重建完美 UI，不用真实录屏——更干净但略显"完美得不真实"

# Batch 3: Feb 2026（17 个视频）

## 1. 视频类型分类

**四大制作层级：**

**Tier A — 精致动效图形（7 个）**：V01 Opus 4.6、V03 Built with Opus 4.6、V05 生日、V07 Figma、V13 Security、V16 Remote Control、V17 定时任务。使用设计好的合成画面——模拟编辑 UI、假终端窗口、像素吉祥物。

**Tier B — 增强录屏（4 个）**：V02 Excel、V04 Cowork Windows、V06 Sonnet 4.6、V08 桌面预览。真实产品 UI 配生活场景桌面模型或合成覆盖层。

**Tier C — 黑客松演示（5 个，社区提交）**：V09-V12、V14。原始录屏或实况 vlog。最少编辑。176-180 秒。

**Tier D — 实况产品演示（1 个）**：V15 Cowork 发布（14.6M views）。真实人物在宿舍/公寓里演示。

## 2. 视觉风格

**色彩体系：**
- **暖米/奶油（主导）**：V01、V03、V04、V05、V06 都用暖白色/奶油背景。2026 年 2 月的 Claude 品牌调色板——"纸质般"的编辑温暖感。
- **深色终端炭灰**：V08、V10、V11、V13、V14 深色模式代码编辑器。
- **鼠尾草绿**：V16、V17 柔和鼠尾草绿 + 波浪图案背景。
- **高对比度单色**：V01 纯黑字白底编辑排版。

**品牌**：Claude 星号 logo（珊瑚/赤陶色）在所有官方视频中一致。

## 3. 字体

- 主标题：高对比度衬线体（Editorial New 风格）。例："Claude now integrations."、"Built with Opus 4.6"
- 副标题：无衬线体
- 代码：等宽体
- 特点：衬线标题用句子式大小写带句号——对话感

## 4. 转场

- **硬切**：最常见
- **垂直滚动/滑动**：V01 模拟新闻流
- **弹性弹入**：V07 Figma logo、V04 图标动画
- **光扫/擦除**：V04 文字渐变扫过
- **合成覆盖溶解**：V08、V13 终端覆盖层带柔和阴影
- **淡出到米色**：V03、V05

## 5. 芭比粉与品牌演变

| 类型 | 时长 | 场景持续 | 节奏 |
|------|------|----------|------|
| 短形式 | 10-12s | 单/双帧 | 充当动画海报 |
| 中形式 | 25-50s | 3-5 场景，5-12s | V13 最动态 |
| 长产品演示 | 75-120s | 清晰起/中/终 | 8-15s/场景 |
| 黑客松演示 | 176-180s | 长未断录屏 | 开发者工作流决定 |

## 6. 开场钩子

**文字优先**：V01（"Claude now integrations."）、V06（渐变擦除揭示）
**视觉优先**：V07（Figma logo 弹性弹入）、V16（终端已在运行——倒叙法）

**关键发现**：浏览量前 5 的视频（V13: 26.2M、V15: 14.6M、V01: 10.6M、V16: 10M、V08: 9.3M）都用直接、不废话的开头。无 logo 入场。

## 7. 结尾模式

无 CTA 结尾卡。所有视频以内容结束：
- V01：最终文字卡 + 集成名称
- V06、V08：以产品 UI 结束，暗示"试试看"
- V13：终端显示安全扫描完成
- V16：待办列表全部勾完

## 8. 互动数据发现

| 视频 | 浏览量 | 类型 | 关键发现 |
|------|--------|------|----------|
| V13 Claude Code Security | **26.2M** | 动效图形 | 安全内容驱动大量互动 |
| V15 Cowork 发布 | **14.6M** | 实况 | 最不精致但互动最高 |
| V01 Opus 4.6 | **10.6M** | 动效图形 | 重大模型发布 |
| V16 Remote Control | **10M** | 混合 | 10 秒获千万浏览 |

**关键发现：**
1. 安全内容主导互动
2. 实况真实性胜过精致度
3. 超短视频也能获巨大传播（V16 10 秒 10M）
4. 方形格式可行（V16 2560x2560）
5. 低分辨率不是障碍
6. 黑客松视频有机传播极低——服务社区建设而非营销

## 9. 关键发现

1. **暖米色是主导品牌背景**——有意远离纯白
2. **衬线字体用于标题**——编辑/高端定位
3. **合成终端覆盖层**是标志性技术（V08、V13、V16、V17）
4. **像素艺术吉祥物**用于社区/活动内容——Lo-fi 开发者文化美学
5. **无结尾卡或 CTA**——每个视频以内容结束
6. **即时钩子**——无 logo 入场，前 2 秒展示产品
7. **方形格式（1:1）**用于短社交视频
8. **两大内容轨道**：精致 Anthropic 营销 vs 原始社区黑客松
9. **带动效轨迹的动画光标**（V08、V13）是独特制作技术
10. **4K（3840x2160）**选择性用于需要 UI 文字清晰度的录屏

# Batch 4: Mar–May 2026（24 个视频）

包含两个最高互动视频：77.9M 和 63.5M 浏览。

## 1. 视频类型分类

**Tier A — 精致动效/合成产品演示（14 个）**
使用模拟 UI 环境而非原始录屏。"屏幕"展示的是重建的、清理过的 mockup，合成在设备框架（手机、笔记本、显示器）上，漂浮在干净背景上。代表：Code Review、Excel/PowerPoint、Interactive Charts、Computer Use（77.9M）、Managed Agents、Claude Design（63.5M）。

关键技术：设备框架（iPhone、MacBook、外接显示器）是 3D 渲染 mockup 带微妙投影。内部 UI 内容是动画录屏或高保真 Figma 风格 mockup。

**Tier B — 动效图形/文字驱动（7 个）**
更短更抽象。依赖品牌元素、文字、简单图形形状的动画。代表：Thank You（8.2s）、Code with Claude Conf、Auto Mode（12.7s）、Agent View（38.8s）。

**Tier C — 混合（实况/音频 + 图形）（3 个）**
桌面重新设计用带叙述的真实录屏。Live from Code with Claude 是真实会议录像。

## 2. 视觉风格

**主导调色板：暖白/奶油背景**
最标志性视觉特征是一致使用暖米色/奶油色（#FBFAF6 到 #F5F0E8）作为主背景。出现在至少 16/24 个视频中。比纯白更柔和高级，创造"纸质"质感。

**次级调色板：深色模式 UI + 暖背景**
产品 UI 几乎普遍使用深色模式（深炭灰 #1A1A2E 到 #2D2D3D）配鲜艳强调色：
- **赤陶/烧橙色**（#D67C64）：主品牌强调色，用于 Claude 头像、按钮、聊天气泡、装饰性涂鸦
- **蓝绿/青色**（#4ECDC4）：次强调色，用于激活状态和进度指示
- **柔和鼠尾草绿**：Claude Design 视频的主题选项
- **鲜艳薄荷绿**：Computer Use 视频的操作按钮

## 3. 字体

- 主字体：现代几何无衬线体（Inter/SF Pro/Public Sans 风格）
- 中等粗细正文、粗体标题、全大写小标签
- 终端/代码语境：等宽字体
- 文字作为 UI vs 文字作为注释：视频中"文字覆盖层"实际是产品界面的一部分（对话性而非额外添加）

## 4. 转场

**主要：硬切 + 动画元素入场**
场景间用硬切，但每个场景内容有动画（淡入上移、滑入、绘制）。

**其他转场：**
- **淡出到暖背景**：Computer Use（77.9M）中米色背景本身就是转场设备
- **绘制动画**：Interactive Charts 用粗黑笔画"绘制"自己
- **涂鸦/笔画连接器**：Computer Use 用标志性手绘赤陶涂鸦连接手机和桌面
- **缩放到 UI**：Office GA 从总览缩放到 UI 交互
- **从画面外滑入**：Managed Agents、Creative Tools

**没有慢淡入或溶解**——节奏干脆现代。

## 5. 节奏

| 类别 | 平均场景时长 | 节奏 |
|------|-------------|------|
| 功能演示（60-96s） | 4-8s/场景 | 有度量的，教程式 |
| 功能演示（40-60s） | 3-5s/场景 | 中速，故事式 |
| 短公告（<20s） | 2-3s/场景 | 快速、有力 |
| Thank You / Conf（<12s） | 单场景 | 最少 |

## 6. 开场钩子

**模式 A — 干净品牌揭示（最常见，14 个视频）**
暖白/奶油背景上，单个元素淡入或绘制：Claude 星号 logo、功能线稿图标、或功能名文字。无声音，无多余动作。例：#1（点阵）、#3（笔画）、#6（光标图标）、#14（调色板图标）。

**模式 B — 直接产品画面（6 个视频）**
直接展示 UI 截图或设备 mockup。无前戏。

**模式 C — 文字/标题卡（4 个视频）**
用动画文字陈述公告。

**顶级视频的特殊之处：**
- Computer Use（77.9M）：极小光标图标在巨大米色负空间中——极端极简引发好奇心
- Claude Design（63.5M）：线稿调色板图标，然后"Design"淡入——有意延缓文字出现

两者都用**"少即是多"钩子**：第一帧的极端极简迫使观众停下来解码。

## 7. 结尾模式

**模式 A — 暖背景 + logo（最常见，12 个）**
回到暖白背景，Claude 星号 logo 居中。有意地在动画演示后制造"干净呼气"效果。

**模式 B — 最终产品画面 + logo（8 个）**
最后帧展示产品的完成状态 + Claude 品牌。

**模式 C — 文字 CTA（4 个）**
以行动号召结束："Register now"、"Sign up"、活动详情。

**一致性**：所有 24 个视频最后帧都有 Claude 品牌可见。

## 8. 叙事弧线

**标准功能公告弧（18 个视频）：**
1. Hook：功能名/图标揭示（0-3s）
2. Context：展示问题或用户需求（3-8s）
3. Demo：功能动画演示（8-70%）
4. Impact：展示结果，多个用例（70-90%）
5. Close：品牌/CTA（90-100%）

**特殊叙事变体：**
- Computer Use（77.9M）：**"命令与执行"叙事**——左到右视觉隐喻：手机 → 赤陶涂鸦（AI 处理）→ 桌面显示器（AI 操作）
- Claude Design（63.5M）：**"画廊揭示"叙事**——从纯抽象渐进到复杂 UI 设计，像设计作品集评审
- Managed Agents（21.6M）：**"终端叙事"**——通过 CLI 命令和输出讲述故事
- Thank You（12.7M）：**"感恩时刻"**——8.2 秒。像素吉祥物 + 终端 + "whatever you've been putting off..."
- Office GA（27.7M）：**"生态系统扫描"**——依次展示 Excel、PowerPoint、Word

## 9. 互动数据发现

| 层级 | 视频 | 浏览量范围 |
|------|------|-----------|
| 超级（50M+） | #6 Computer Use, #14 Design | 63-78M |
| 高（10-30M） | #1, #2, #3, #4, #9, #10, #16, #17, #18, #21, #23 | 11-27M |
| 中（2-10M） | #7, #13, #19, #22, #24 | 2-7M |
| 低（<2M） | #5, #8, #11, #12, #15, #20 | 未知/低 |

**超级视频的差异：**
1. **4K 分辨率**：都是 3840x2160
2. **极端极简开场**：巨大负空间 + 单焦点元素
3. **更长时长**：73-81 秒——观众愿意看完整功能演示
4. **通用功能**：跨专业吸引力，不只是开发者
5. **视觉精致度更高**：更精炼的动画和分层
6. **空间叙事**：横向构图讲故事

**与浏览量无关的因素：**
- 时长本身：#2 最长（96.4s）但只有 12.5M
- 画幅比例：竖屏视频低浏览，但横屏也有低的
- 话题：开发者聚焦的视频（#1 Code Review 23.5M）也能高

# 跨批次总结

## 全局视觉语言："Anthropic Warm" 美学

78 个视频建立了一套高度独特的视觉语言，将 Claude 与竞品区分开：

**核心三件套：**
1. **暖白/奶油背景**（非纯白）——纸质般的温暖质感
2. **赤陶/烧橙色强调**——Claude 最即时辨识的视觉元素
3. **深色模式 UI**——所有产品界面都以深色展示

**与竞品的差异：**
- 远离 OpenAI/Google 的冷蓝/黑渐变
- 远离 Apple 的纯黑白
- 暖色 + 智能 = 学术感而非企业感

## 两大制作轨道

| 轨道 | 特点 | 代表 |
|------|------|------|
| 官方精致营销 | 4K、模拟 UI、动效图形、合成设备 mockup | 所有产品发布视频 |
| 社区/实况内容 | 原始录屏、真人出镜、低编辑 | 黑客松、Cowork 实况演示 |

## 制作技术演变

- **2025 Q4**：浮动应用窗口在品牌背景上，模拟光标
- **2026 Q1**：合成设备框架（手机/笔记本/显示器）+ 深色 UI + 赤陶强调
- **2026 Q2**：空间叙事（左到右流动）、手绘涂鸦连接器、极端极简开场

## 共同规则

1. **无 logo 入场**——产品直接在前 2 秒展示
2. **无结尾 CTA 卡**（绝大多数）——以内容结束
3. **无相机运动**——所有运动来自内容动画
4. **硬切为主**——没有花哨的 3D 转场
5. **衬线标题 + 句子式大小写**——编辑/高端感
6. **深色模式 UI 恒定**——暗示"高级"、"技术"、"专注"
7. **设备 mockup 作为主要视觉设备**——同时展示多个屏幕
8. **涂鸦/笔画**作为"人性化"装饰元素——提醒背后有创意之手

## 互动驱动因素

**高互动视频的共同特征：**
1. 4K 分辨率（精致感）
2. 极端极简开场（好奇心驱动停留）
3. 跨专业通用功能（更广分享面）
4. 更长但有节奏的叙事（70-80 秒）
5. 空间/横向叙事构图

**不决定互动的因素：**
- 时长本身
- 画幅比例
- 是否开发者聚焦

## 音乐/音频（从视觉推断）

- 快节奏动效视频：可能有节拍同步的打击乐/电子配乐
- 产品演示：可能有环境/轻音乐
- 终端/开发者视频：可能最少或无音乐
- 品牌宣言：可能静音或单一音调
- 实况视频：人声叙述 + 最少配乐
