# Anthropic 是怎么做视频做到 7800 万播放的

对 77 个 @claudeai 官方视频（2025-10 至 2026-05）的系统性分析。提取了制作方法论、设计系统、叙事框架、互动规律。

## 5 个核心发现

### 1. 从不录真实屏幕——重建完美 UI

Claude 视频里的每一个"截图"都是重新制作的。像素级完美的 UI mockup，合成在 3D 渲染的设备框架上（MacBook、iPhone、显示器），悬浮在暖色背景上。没有浏览器边框、书签栏、通知角标。

**为什么有效：** 消除视觉噪音。每一帧都品牌安全。没有意外的 tab、尴尬的书签、过时的 UI 元素。

### 2. "少即是多"的开场是最高播放模式

两个最高播放的视频（7790 万和 6350 万）用同一个方式开场：暖色背景上一个极小的图标。没有文字。没有动画。只有负空间和一个焦点。

这制造了**认知缺口**——大脑无法瞬间理解画面，于是投入注意力去解码。等产品名在 0.8-1.2 秒后淡入时，观众已经被钩住了。

那个 10 秒拿到 1000 万播放的视频？同样的原理。极端极简。一个元素。结束。

### 3. 没有 logo 开场，没有结尾 CTA——从来没有

77 个视频中：
- **0** 个以 logo 动画开头
- **0** 个以"立即注册"或任何行动号召结尾

这是刻意的品牌定位。logo 开场 = "我们需要介绍自己"。CTA = "我们需要你"。Claude 两者都不做——产品在第 1 帧出现，视频以暖色背景上的 logo 淡出结束。

传达的信息：*我们的产品不需要自我推销。*

### 4. "展示思考过程，不只是结果"驱动互动

可视化 AI 过程的视频——任务列表逐行变绿、终端命令滚动、节点图展开——持续比只展示最终结果的视频表现更好。

这不只是制作技巧，是**信任架构**。展示过程让 AI 不那么像黑盒。观众可以验证："它确实做了这些步骤。"

最极端的例子：Computer Use（7790 万）展示 Claude 逐个应用点击真实操作系统。不是模拟。不是加速太多。真实光标，真实点击，真实犹豫。

### 5. 只用硬切——零花哨转场

77 个视频中：
- ~60% 硬切
- ~15% 淡出到暖色背景
- ~10% 滑入
- ~0% 溶解、变形、3D 翻转、粒子效果

每个转场都在 2 秒以内。没有电影级溶解。没有炫目动效转场。哲学：如果每一帧都值得看，你不需要为切到它而道歉。

## 数据驱动的洞察

### "Introducing" 的播放量是 "now available" 的 5 倍

首发宣布视频平均 **2360 万播放**。功能扩展视频平均 **460 万**。"Introducing" 不只是文案——它传递的是"新物种"而非"版本更新"。

### 60-90 秒是甜蜜点，之后断崖下跌

| 时长 | 平均播放 |
|------|---------|
| <15s | 300 万 |
| 30-60s | 730 万 |
| **60-90s** | **1560 万** |
| >90s | 290 万 |

60-90 秒足够展开完整叙事弧（Hook → Demo → Magic → Result）。30 秒以下觉得不完整。90 秒以上注意力衰减。

### 脉冲式发布，不是均匀滴灌

77 个视频分布在 222 天 = 平均每 2.9 天一个。但 77% 的天数没有发布。Anthropic 用的是**密集战役**——3-5 天窗口内每天 2-3 个视频，然后安静期。

最极端：2026 年 2 月一个月 23 个视频（占总量 30%），围绕 Opus 4.6 和 Cowork 发布。单日最高：2 月 20 日，24 小时内 7 个视频。

**为什么脉冲有效：** 平台算法奖励话题集中度。密集发布制造"到处都是 Claude"的感知，均匀滴灌做不到。

### 宽度 vs 深度：两种不同的游戏

- **宽度路线**（品牌曝光）：Computer Use — 7790 万播放，14,467 转发。百万人看了，少有人收藏。
- **深度路线**（开发者忠诚）：Agent View — 230 万播放，但 0.32% 收藏率和 686 条回复。观众少，但每个人都深度参与。

两者都重要。宽度建品牌。深度建社区。Anthropic 同时跑两条线。

### 周一是发布日

| 星期 | 平均播放 |
|------|---------|
| **周一** | **1260 万** |
| 周五 | 940 万 |
| 周二-周四 | 470-550 万 |

周一内容搭乘周末到工作日的注意力浪潮。周五内容获得周末扩散。

## 制作公式（一句话版）

```
暖色画布 (#FBFAF6) + 深色 UI (#1A1A2E) + 赤陶强调色 (#D67C64)
+ 在 3D 设备 mockup 上重建完美 UI
+ 衬线标题，句子式大小写带句号。
+ 硬切。无 logo 开场。无 CTA。
+ 用 Task Sequence 做 Magic Moment
+ 前 3 秒 Hook。前 15 秒 Magic Moment。
= Claude 视频
```

## 竞品定位

| | Claude | ChatGPT | Gemini | Apple Intelligence |
|---|--------|---------|--------|-------------------|
| 主色调 | 暖白 + 赤陶 | 冷蓝 + 黑渐变 | 白 + 多彩 | 纯黑 + 纯白 |
| 情绪 | 学术、温暖、思考 | 科技、酷、前沿 | 活泼、友好、大众 | 极简、高端、克制 |
| 字体 | 衬线标题（编辑感） | 无衬线（科技感） | Google Sans（品牌感） | SF Pro（系统感） |
| 真人出镜 | 77 个中 1 个 | 偶尔 | 频繁 | 从不 |
| 结尾 CTA | 从不 | 有时 | 总是 | 品牌卡 |

Claude 的视觉语言是对 AI 行业默认冷蓝色系的刻意偏离。温暖 + 智能 = 学术感，而非企业感。

## 适配到你的产品

**直接复用：** 硬切、无 logo 开场、无 CTA、句子式标题带句号、字重 500/600/700、Task Sequence、3-8 秒场景、反模式清单、脉冲发布节奏、60-90 秒甜蜜点。

**需要适配：** 色彩系统（用你的品牌色但保持暖色画布 + 深色 UI 的层级）、字体（用你的品牌字体但保持大小层级）、设备 mockup（不能做 3D 渲染就用截图加阴影）。

**核心原则：** 每个制作决策都要有理由。Claude 的选择不是随意的审美——是品牌策略通过动效的表达。抄逻辑，不要抄像素。
