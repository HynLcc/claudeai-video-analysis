# Anthropic는 어떻게 7,800만 조회수의 동영상을 만들었는가

77개의 @claudeai 공식 동영상(2025년 10월 ~ 2026년 5월)에 대한 체계적 분석. 제작 방법론, 디자인 시스템, 내러티브 프레임워크, 인게이지먼트 패턴을 추출했습니다.

## 5가지 핵심 인사이트

### 1. 실제 화면을 녹화하지 않는다 — 완벽한 UI를 재구축한다

Claude 동영상의 모든 "스크린샷"은 제작된 것입니다. 픽셀 단위로 완벽한 UI 모의 화면을 3D 렌더링된 디바이스 프레임(MacBook, iPhone, 모니터)에 합성하고, 따뜻한 배경 위에 띄웁니다. 브라우저 크롬 없음, 북마크 바 없음, 알림 뱃지 없음.

**효과적인 이유:** 시각적 노이즈를 제거합니다. 모든 프레임이 브랜드 안전합니다. 실수로 연 탭도, 창피한 북마크도, 다음 주 업데이트로 구식이 될 UI 요소도 없습니다.

### 2. "Less Is More" 훅이 최고 조회수 패턴

가장 많이 조회된 두 동영상(7,790만과 6,350만)이 같은 방식으로 시작: 넓은 따뜻한 배경 위의 작은 아이콘. 텍스트 없음. 애니메이션 없음. 네거티브 스페이스와 단일 초점만.

이는 **인지 격차**를 만듭니다 — 뇌가 프레임을 즉시 해석할 수 없어 이해하려 주의력을 투자합니다. 0.8~1.2초 후 제품명이 페이드인될 때, 시청자는 이미 빠져들었습니다.

1,000만 조회수를 기록한 10초 동영상? 같은 원리. 극단적 미니멀리즘. 하나의 요소. 끝.

### 3. 로고 인트로 없음, 엔딩 CTA 없음 — 절대

77개 동영상 중:
- **0개**가 로고 애니메이션으로 시작
- **0개**가 "지금 가입하세요!" 같은 CTA로 끝남

이것은 의도적인 브랜드 포지셔닝. 로고 인트로는 "우리를 소개해야 합니다". CTA는 "당신이 필요합니다". Claude는 둘 다 하지 않습니다 — 제품이 1프레임에 나타나고, 동영상은 따뜻한 배경의 조용한 로고로 페이드아웃됩니다.

메시지: *우리 제품은 스스로를 팔 필요가 없습니다.*

### 4. "결과뿐만 아니라 사고 과정을 보여주기"가 인게이지먼트를 견인

AI의 과정을 시각화하는 동영상 — 작업 목록이 녹색으로 체크, 터미널 명령어가 스크롤, 노드 그래프가 확장 — 이 최종 결과만 보여주는 동영상보다 일관되게 높은 성과를 냅니다.

이것은 제작 기술이 아닙니다. **신뢰 아키텍처**입니다. 과정을 보여주면 AI가 블랙박스처럼 느껴지지 않습니다. 시청자는 검증할 수 있습니다: "이 단계들을 실제로 수행했구나".

가장 극단적인 예: Computer Use(7,790만)는 Claude가 실제 OS를 앱별로 클릭하는 과정을 보여줍니다. 시뮬레이션 아님. 너무 빠르게 재생하지 않음. 진짜 커서, 진짜 클릭, 진짜 망설임.

### 5. 하드 컷만 — 화려한 전환 효과 제로

77개 동영상 중:
- ~60% 하드 컷
- ~15% 따뜻한 배경으로 페이드아웃
- ~10% 슬라이드인
- ~0% 디졸브, 모핑, 3D 플립, 파티클 효과

모든 전환은 2초 이내. 시네마틱 디졸브 없음. 화려한 모션 그래픽 전환 없음. 철학: 각 프레임이 볼 가치가 있다면, 전환하는 것을 사과할 필요가 없습니다.

## 데이터 기반 인사이트

### "Introducing"은 "now available"의 5배 조회수

신규 발표 동영상(예: "Introducing Claude Cowork") 평균 **2,360만 조회수**. 기능 확장 동영상(예: "Claude is now available in Excel") 평균 **460만**. "Introducing"은 단순한 카피가 아닙니다 — "새 종" vs "버전 업데이트"의 신호입니다.

### 60~90초가 스위트스팟 — 그 다음은 급락

| 길이 | 평균 조회수 |
|------|-----------|
| <15초 | 300만 |
| 30~60초 | 730만 |
| **60~90초** | **1,560만** |
| >90초 | 290만 |

60~90초면 완전한 내러티브 아크(훅 → 데모 → 매직 → 결과)를 펼칠 수 있습니다. 30초 미만은 불완전하게 느껴집니다. 90초 초과는 주의력이 저하됩니다.

### 펄스 릴리즈 — 균일한 드립이 아님

77개 동영상이 222일에 분산 = 평균 2.9일에 1개. 그러나 77%의 날에 릴리즈 없음. Anthropic는 **버스트 캠페인** 사용 — 3~5일 윈도우에서 하루 2~3개, 이후 조용한 기간.

가장 극단적: 2026년 2월 한 달에 23개(전체의 30%), Opus 4.6과 Cowork 런칭에 집중. 최다 기록일: 2월 20일, 24시간 내 7개.

**펄스가 효과적인 이유:** 플랫폼 알고리즘이 주제 집중도를 평가합니다. 관련 동영상의 집중은 "Claude가 어디에나 있다"는 인식을 만들고, 균일한 드립으로는 불가능합니다.

### 폭 vs 깊이: 두 가지 다른 게임

- **폭의 게임** (브랜드 노출): Computer Use — 7,790만 조회수, 14,467 리트윗. 수백만이 봤지만 저장한 사람은 적음.
- **깊이의 게임** (개발자 충성도): Agent View — 230만 조회수, 0.32% 북마크율, 686개 답글. 시청자는 적지만每个人都 깊게 관여.

둘 다 중요. 폭이 브랜드를 구축. 깊이가 커뮤니티를 구축. Anthropic는 두 트랙을 동시에 운영.

### 월요일이 런칭 데이

| 요일 | 평균 조회수 |
|------|-----------|
| **월요일** | **1,260만** |
| 금요일 | 940만 |
| 화~목 | 470~550만 |

월요일 게시물은 주말에서 근무일로의 주의력 파도를 탑니다. 금요일 게시물은 주말 확산을 얻습니다.

## 자신의 제품에 적용하기

**그대로 사용:** 하드 컷, 로고 인트로 없음, CTA 없음, 문장 케이스 제목 + 마침표, 폰트 웨이트 500/600/700, 태스크 시퀀스, 3~8초 장면, 안티패턴 목록, 펄스 릴리즈 리듬, 60~90초 스위트스팟.

**브랜드에 맞게 조정:** 컬러 시스템(브랜드 색상을 사용하되 따뜻한 캔버스 + 다크 UI 계층 유지), 타이포그래피(브랜드 폰트를 사용하되 사이즈 계층 유지), 디바이스 모의 화면(3D 렌더링이 불가능하면 스크린샷 + 그림자로 대체).

**핵심 원칙:** 모든 제작 결정에는 이유가 있어야 합니다. Claude의 선택은 임의적인 미학이 아닙니다 — 모션을 통한 브랜드 전략의 표현입니다. 논리를 복사하세요, 픽셀을 복사하지 마세요.
