# Contributing

This repository contains analysis of Anthropic's Claude product video strategy. Contributions welcome.

## How to contribute

### Data updates
If you have new Claude video data (tweet IDs, metadata, engagement numbers), add entries to `data/metadata.json` following the existing format.

### Analysis improvements
- Found an error in the methodology? Open an issue or PR.
- Have additional data dimensions to analyze? Share your approach.

### Translations
The repository supports 7 languages. If you find translation issues:
- `README.md` — English
- `README.zh.md` — Chinese
- `README.ja.md` — Japanese
- `README.ko.md` — Korean
- `README.es.md` — Spanish
- `README.fr.md` — French
- `README.pt.md` — Portuguese

Each README contains the full methodology in its language.

### What NOT to contribute
- Don't add Anthropic's actual video files (copyright).
- Don't add internal Teable/product-specific references — this is a public, generic analysis.
