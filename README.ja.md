# Anthropic はいかにして 7,800万再生の動画を作ったか

## 5つの主要な発見

### 1. 本物の画面は録画しない——完璧なUIを再構築する

Claude動画のすべての「スクリーンショット」は作られたもの。ピクセル完璧なUIモックアップを3Dレンダリングされたデバイスフレーム（MacBook、iPhone、モニター）に合成し、暖色の背景に浮かせる。ブラウザのクロームなし、ブックマークバーなし、通知バッジなし。

**なぜ効くのか：** 視覚ノイズを排除。すべてのフレームがブランドセーフ。誤ったタブも、恥ずかしいブックマークも、来週のアップデートで古くなるUI要素もない。

### 2. 「Less Is More」のフックが最も高い再生数を記録

最も再生の多かった2本の動画（7,790万と6,350万）は同じオープニング：広大な暖色背景の上の小さなアイコン。テキストなし。アニメーションなし。ネガティブスペースと単一の焦点だけ。

これは**認知ギャップ**を生む——脳はフレームを即座に理解できないため、注意力を投入して解読しようとする。0.8〜1.2秒後にプロダクト名がフェードインする頃には、視聴者はすでに引き込まれている。

1,000万再生を記録した10秒動画？同じ原理。極端なミニマリズム。1つの要素。終わり。

### 3. ロゴイントロなし、エンディングCTAなし——絶対に

77本の動画において：
- **0本**がロゴアニメーションで始まる
- **0本**が「今すぐ登録！」などのCTAで終わる

これは意図的なブランドポジショニング。ロゴイントロは「自分たちを紹介する必要がある」。CTAは「あなたが必要だ」。Claudeはどちらもしない——プロダクトが1フレーム目に登場し、動画は暖色背景の静かなロゴへとフェードアウトする。

メッセージ：*私たちのプロダクトは売り込む必要がない。*

### 4. 「結果だけでなく思考過程を見せる」がエンゲージメントを駆動

AIの過程を可視化する動画——タスクリストが緑にチェック、ターミナルコマンドがスクロール、ノードグラフが展開——は、最終結果だけを見せる動画より一貫して高い成果を出す。

これは制作テクニックではない。**トラストアーキテクチャ**だ。過程を見せることで、AIがブラックボックスではなくなる。視なる。視聴者は検証できる：「実際にこれらのステップを実行した」。

最も極端な例：Computer Use（7,790万再生）はClaudeが実際のOSをアプリごとにクリックする様子を見せる。シミュレーションではない。早回ししすぎていない。本物のカーソル、本物のクリック、本物のためらい。

### 5. ハードカットのみ——凝ったトランジション一切なし

77本の動画において：
- ~60% ハードカット
- ~15% 暖色背景へのフェードアウト
- ~10% スライドイン
- ~0% ディゾルブ、モーフィング、3Dフリップ、パーティクルエフェクト

すべてのトランジションは2秒以内。シネマティックなディゾルブなし。派手なモーショングラフィックのトランジションなし。哲学：各フレームが見る価値があれば、カットすることを詫びる必要はない。

## データドリブンのインサイト

### 「Introducing」は「now available」の5倍の再生数

新規発表動画（「Introducing Claude Cowork」など）は平均**2,360万再生**。既存機能の拡張動画（「Claude is now available in Excel」など）は平均**460万**。「Introducing」は単なるコピーではない——「新種」vs「バージョン更新」のシグナルだ。

### 60〜90秒がスウィートスポット——その後は急降下

| 時間 | 平均再生数 |
|------|-----------|
| <15秒 | 300万 |
| 30〜60秒 | 730万 |
| **60〜90秒** | **1,560万** |
| >90秒 | 290万 |

60〜90秒で完全なナラティブアーク（フック → デモ → マジック → リザルト）を展開できる。30秒未満は不完全に感じる。90秒超は注意力が低下する。

### パルスリリース——均一なドリップではない

77本の動画が222日に分散 = 平均2.9日に1本。しかし77%の日にリリースなし。Anthropicは**バーストキャンペーン**を使用——3〜5日のウィンドウで1日2〜3本、その後静寂期。

最も極端なケース：2026年2月に1ヶ月で23本（全コンテンツの30%）、Opus 4.6とCoworkのローンチに集中。最多記録日：2月20日、24時間で7本。

**なぜパルスが効くのか：** プラットフォームアルゴリズムはトピック集中度を評価する。関連動画の集中は「Claudeがどこにでもある」感覚を作り、均一なドリップでは実現できない。

### 幅 vs 深さ：2つの異なるゲーム

- **幅の勝負**（ブランド露出）：Computer Use — 7,790万再生、14,467リツイート。数百万人が見たが、保存した人は少ない。
- **深さの勝負**（開発者ロイヤルティ）：Agent View — 230万再生だが、0.32%のブックマーク率と686件のリプライ。視聴者は少ないが、一人ひとりが深く関与。

両方大事。幅がブランドを築く。深さがコミュニティを築く。Anthropicは2つのトラックを同時に走らせる。

### 月曜日がローンチデー

| 曜日 | 平均再生数 |
|------|-----------|
| **月曜** | **1,260万** |
| 金曜 | 940万 |
| 火〜木 | 470〜550万 |

月曜の投稿は週末から平日への注目波に乗る。金曜の投稿は週末の増幅を得る。

## 制作フォーミュラ（一句话版）

```
暖色キャンバス (#FBFAF6) + ダークUI (#1A1A2E) + テラコッタアクセント (#D67C64)
+ 3Dデバイスモックアップ上の完璧なUI再構築
+ セリフ体タイトル、センテンスケース＋ピリオド
+ ハードカット。ロゴイントロなし。CTAなし。
+ タスクシーケンスで「マジックモーメント」
+ 0〜3秒でフック。15秒以内にマジックモーメント。
= Claude動画
```

Claudeのビジュアル言語は、AI業界のデフォルトである寒色ブルーパレットからの意図的な逸脱。温かさ＋知性＝学術的、而非企業的。

## あなたのプロダクトに応用する

**そのまま使える：** ハードカット、ロゴイントロなし、CTAなし、センテンスケースのタイトル＋ピリオド、フォントウェイト500/600/700、タスクシーケンス、3〜8秒シーン、アンチパターンリスト、パルスリリースリズム、60〜90秒スウィートスポット。

**ブランドに合わせて調整：** カラーシステム（ブランドカラーを使いつつ暖色キャンバス＋ダークUIの階層を維持）、タイポグラフィ（ブランドフォントを使いつつサイズ階層を維持）、デバイスモックアップ（3Dレンダリングができない場合はスクリーンショット＋シャドウで代替）。

**基本原則：** すべての制作決定には理由がある。Claudeの選択は恣意的な美学ではない——モーションを通じたブランド戦略の表現だ。理由をコピーし、ピクセルをコピーするな。
